Documentação da API FipeData

A API do FipeData permite a consulta direta aos dados brutos e históricos da Tabela FIPE armazenados no nosso sistema. O formato de resposta padrão é JSON.

Atenção: Codificação de URLs (URL Encoding)

Ao realizar consultas que contenham espaços em branco ou caracteres especiais, você deve substituir esses caracteres pelos seus respectivos códigos HTML/URL para evitar que o navegador ou o sistema cortem a sua pesquisa.

O caso mais comum é o espaço em branco, que deve ser substituído por %20 ou +.

❌ Errado: /api/consulta?marca=vw volkswagen (O espaço quebra o link)
✅ Correto: /api/consulta?marca=vw%20volkswagen (Uso do %20 no lugar do espaço)

Outros caracteres úteis:

  • Espaço ( ) = %20
  • Barra (/) = %2F
  • E Comercial (&) = %26

Dica: Em linguagens de programação, você pode usar funções nativas para fazer isso automaticamente, como encodeURIComponent("vw volkswagen") no JavaScript ou urllib.parse.quote("vw volkswagen") no Python.

Endpoint Principal

GET /api/consulta

Consulta genérica e flexível do histórico de veículos da Tabela FIPE. Permite múltiplos filtros combinados.

Parâmetros de Busca (Query Strings)

Parâmetro Descrição Exemplo
fipe Código FIPE exato do veículo (formato: 000000-0) ?fipe=004315-0
marca Nome da marca (busca aproximada). Lembre-se do %20. ?marca=fiat ou ?marca=aston%20martin
modelo Nome do modelo (busca aproximada). ?modelo=palio%20fire
ano_modelo Filtra por ano específico de fabricação do veículo. ?ano_modelo=2020
mes Mês de referência FIPE (formato MM, ex: 1 = Janeiro). ?mes=10
ano Ano de referência (quando o preço foi publicado). ?ano=2023
limit Limita a quantidade de resultados retornados (Padrão: 100, Máx: 1000). ?limit=50

Exemplos de Uso Combinado

Buscando todos os Palios ano 2020 cadastrados na FIPE em Janeiro de 2023:

GET /api/consulta?marca=fiat&modelo=palio&ano_modelo=2020&mes=1&ano=2023

Campo Tipo Descrição Exemplo

marca string (opcional) Nome da marca do veículo. "VW - VolksWagen"

Pesquisa de Ofertas Reais (OLX)

POST /api/olx

Consulta até 15 ofertas reais anunciadas na OLX Brasil com suporte a filtros regionais e de faixa de preço. Traz preços praticados, quilometragem, ano, cor, motor, localização e links diretos dos anúncios.

Parâmetros (JSON no corpo da requisição):

Campo Tipo Descrição Exemplo
modelo string (obrigatório) Nome do modelo, versão ou código FIPE com ano (ex: cod_fipe|ano). "Gol Special 1.0 Total Flex 8V 5p (2015)"
marca string (opcional) Nome da marca do veículo. "VW - VolksWagen"
ano inteiro (opcional) Ano do modelo a ser consultado. 2015
ddd inteiro/string (opcional) Código DDD da região desejada (ex: 11, 19, 21, 31, 41, etc.). 19
estado string (opcional) Sigla da UF (ex: SP, RJ, MG, PR, SC, RS, etc.). "SP"
regiao string (opcional) Nome ou slug da região na OLX. "grande-campinas"
municipio string (opcional) Nome do município para filtro específico. "Campinas"
preco_min numérico (opcional) Preço mínimo desejado em reais. 20000
preco_max numérico (opcional) Preço máximo desejado em reais. 50000
max_results inteiro (opcional) Quantidade máxima de anúncios (padrão: 15, máx: 30). 15

POST /api/ipva/calcular

Calcula a estimativa de IPVA para um ou múltiplos veículos com base no valor da Tabela FIPE, ano do modelo e UF selecionada. Aplica regras estaduais de isenção por tempo de fabricação, cronograma detalhado de parcelamento (opção padrão de 3 parcelas e limite máximo do estado sem juros) e taxa atualizada de licenciamento anual do DETRAN estadual.

Parâmetros (JSON no corpo da requisição):

Campo Tipo Descrição Exemplo
uf string (opcional) Sigla do estado (ex: SP, RJ, SC, MG). Se omitido, usa a UF detectada pelo IP do usuário. "SP"
veiculos array de objetos (opcional) Lista de veículos para cálculo em lote. [{"nome": "Gol 1.0 (2018)", "valor_fipe": 42000, "ano_modelo": 2018}]
valor_fipe numérico (opcional) Valor FIPE único caso não envie o array veiculos. 42000.00
ano_modelo inteiro (opcional) Ano do modelo do veículo (para conferência de isenção por idade). 2018
